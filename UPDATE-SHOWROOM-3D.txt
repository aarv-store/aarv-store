Cara update GitHub Pages:
- Ekstrak ZIP.
- Buka folder katalog-toko-wa-main.
- Upload seluruh isi folder ke repository aarv-store.github.io/aarv-store/ dan pilih Replace files bila diminta.

Catatan teknis:
Viewer ini menggunakan mesh kain 3D melengkung dengan tekstur foto/cut-out depan dan belakang. Putaran 360 derajat bersifat interaktif, tetapi belum merupakan simulasi kain volumetrik penuh seperti hasil CLO3D/Blender dengan model GLB/GLTF. Untuk tingkat realisme tertinggi pada sudut samping, lipatan, dan jatuh kain, tahap berikutnya adalah membuat model kaos boxy fit AЯRV di CLO3D/Blender lalu mengekspornya sebagai GLB/GLTF.
